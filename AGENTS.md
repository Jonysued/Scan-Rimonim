# Scan Rimonim

App independiente: React/Vite, Supabase Auth/Postgres/Storage y API Vercel.
Nunca usar servicios, SDK ni publicación de Base44. Ver README.md.
No publicar secretos ni datos de la finca. Verificar build, lint y pruebas.
La guía web evalúa el encuadre, no mide distancia física. La captura iOS usa LiDAR trasero en equipos compatibles; requiere pruebas en teléfono real. Las estimaciones experimentales no habilitan calibre validado automáticamente ni se agregan a sus promedios.
